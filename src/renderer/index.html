Online model providers

Use cloud models (DeepSeek, OpenAI, OpenRouter, or any OpenAI-compatible API) alongside local ones. API keys are stored encrypted on this PC (Windows DPAPI) and sent only to the provider you saved them for. Enabled providers with a key appear in the sidebar under Online.

MCP extensions

Claude Desktop-style MCP servers give the agent modes extra tools (Filesystem, Desktop Commander, PDF tools…). Enable a server and press Apply.

Skills

Skill folders containing a SKILL.md are injected into the agent's system prompt when enabled. Install from a local folder, git URL, or .zip URL.

Model selection

OCR / vision model

Needs a vision GGUF plus its mmproj-*.gguf projector in the same folder, and llama.cpp b10199 or newer (older builds reject deepseek2-ocr).

Text to speech

Uses the offline Windows voices — no model download, no network. Voices are read from both engines: classic SAPI5 and the modern OneCore set (which usually has more languages installed, e.g. English (India)).
